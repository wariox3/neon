<Aside type="caution" title="Servicio gratuito, sin garantías">
RedEDoc se ofrece **gratis y tal cual**: es un servicio *best-effort*, sin acuerdo de nivel
de servicio, sin disponibilidad comprometida y sin soporte garantizado. Quien lo integre
asume esa condición.
</Aside>

## Qué hace

<CardGrid>
  <Card title="Emite ante la DIAN" icon="document">
    Factura de venta, notas crédito y débito, documento soporte y su nota de ajuste, y
    nómina electrónica.
  </Card>
  <Card title="El pipeline completo" icon="setting">
    Documento → XML UBL 2.1 → CUFE/CUDE → firma XAdES-EPES → envío al Web Service de la
    DIAN → PDF con código QR.
  </Card>
  <Card title="Una API REST y ya" icon="puzzle">
    El ERP se autentica con una llave de API —una cabecera y nada más— y todo el ciclo de
    vida del documento se hace por HTTP.
  </Card>
  <Card title="Conforme al Anexo Técnico" icon="approve-check">
    Anexo Técnico v1.9 (Resolución DIAN 000165 de 2023), con el XML validado contra los
    XSD oficiales y los identificadores verificados contra los ejemplos del Anexo.
  </Card>
</CardGrid>
